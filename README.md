# Taller de Programación

Ejercicios de las guías prácticas realizados durante la materia
Taller de Programación de FIUBA 2do Cuatrimestre 2026.

## Contenido

### Clase 1

- Ahorcado desarrollado en Rust.
- Contador de frecuencia de palabras desarrollado en Rust.
- Buscador de texto completo desarrollado en Rust.

### Clase 2

- Implementación simplificada de `diff` utilizando el algoritmo LCS (Longest Common Subsequence).

### Clase 3

- Simulación de operaciones sobre una cuenta bancaria utilizando concurrencia.
- Uso de threads, `Arc`, `RwLock` y channels para compartir datos y sincronizar operaciones.
